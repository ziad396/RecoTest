# RecoTest
AI-powered Burp Suite assistant for attack surface mapping and intelligent endpoint analysis.
Recotest ## Overview Recotest is an AI-powered security assistant integrated with Burp Suite, designed to help penetration testers discover, map, and analyze a target's attack surface during the reconnaissance phase. Recotest collects and analyzes information such as subdomains, JavaScript files, endpoints, parameters, and technologies. It uses AI to identify interesting attack surfaces, correlate discovered information, prioritize endpoints, and suggest potential vulnerabilities across a wide range of web application vulnerability classes. The goal is not to replace the penetration tester or perform fully automated exploitation. Instead, Recotest assists the tester by reducing repetitive reconnaissance and analysis tasks while keeping the tester in control of the security testing process. ## Key Features - Attack Surface Mapping Collects and organizes subdomains, JavaScript files, endpoints, parameters, and technologies. - AI-Assisted Endpoint Analysis Highlights interesting endpoints for closer review and suggests potential vulnerability classes to consider, without claiming confirmed vulnerabilities.Burp Suite Integration Preparesselected endpoints for manual testing in Burp Repeater. Visual Target Dashboard Displays discovered data in a clear target-based structure. Manual Testing First Designed to assist professional testers, not to automate exploitation.
